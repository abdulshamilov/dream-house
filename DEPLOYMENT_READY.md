## 🎯 Как использовать API на локальной машине

### 1. Запуск сервера
```bash
python manage.py runserver
# или
python manage.py runserver 0.0.0.0:8000
```

### 2. Открыть в браузере
```
http://127.0.0.1:8000/api/
```

### 3. Примеры эндпоинтов (доступны для всех):

**Получить список карточек:**
```
GET http://127.0.0.1:8000/api/cards/?limit=10&page=1
```

**Умный поиск:**
```
GET http://127.0.0.1:8000/api/cards/search/?q=квартира&price_from=1000000&price_to=5000000
```

**API документация (Swagger):**
```
http://127.0.0.1:8000/api/schema/
http://127.0.0.1:8000/api/docs/  (ReDoc)
```

## 🚀 Готово к развертыванию

### Перед production развертыванием:

```bash
# 1. Проверить конфигурацию
python manage.py check --deploy

# 2. Собрать статические файлы
python manage.py collectstatic --noinput

# 3. Запустить миграции
python manage.py migrate

# 4. Создать superuser (если нужно)
python manage.py createsuperuser

# 5. Запустить с Gunicorn
gunicorn config.wsgi:application --bind 0.0.0.0:8000
```

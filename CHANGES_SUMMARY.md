## 🔍 ЧТО ТЕПЕРЬ РАБОТАЕТ

### Режим поиска AI ('search')
```python
POST /api/cards/ai/chat/
{
  "message": "Ищу 2-комнатную квартиру в Махачкале до 5 миллионов",
  "user_preferences": {
    "city": 1,  # Махачкала
    "rooms": 2,
    "price_max": 5000000
  },
  "mode": "search"
}
```
→ AI вернёт подходящие квартиры + совет

### Режим обычного чата ('free')
```python
POST /api/cards/ai/chat/
{
  "message": "Чем отличается монолитное строительство от кирпичного?",
  "mode": "free"
}
```
→ AI даст консультацию без поиска в БД

### Подборки документов
```python
POST /api/cards/1/document-lists/create/
{
  "name": "Правоустанавливающие документы"
}
```

### История просмотров
```python
POST /api/cards/1/view-history/
{
  "duration_seconds": 45
}
```

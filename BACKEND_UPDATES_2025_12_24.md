# Changelog - Правки для управления профилем пользователя

## 2025-12-24 - Улучшения функциональности профиля

### ✅ Реализовано

#### 1. Улучшение смены фото профиля (Update Profile Photo)
- **Файл**: `users/views.py` - `UpdateProfileView`
- **Изменения**:
  - Добавлена валидация размера фото (максимум 5MB)
  - Добавлена валидация типа файла (JPEG, PNG, GIF)
  - Добавлена автоматическая очистка старого фото при загрузке нового
  - Добавлен новый метод DELETE для удаления фото профиля
  - Улучшена документация через Swagger/OpenAPI

#### 2. Добавление метода DELETE для удаления фото
- **Endpoint**: `DELETE /api/users/update-profile/`
- **Возвращает**: HTTP 200 с подтверждением
- **Функциональность**: 
  - Удаляет текущее фото пользователя
  - Автоматически удаляет файл из хранилища
  - Логирует операцию

#### 3. Улучшение удаления аккаунта (Delete Account)
- **Файл**: `users/views.py` - `DeleteAccountView`
- **Изменения**:
  - Добавлена безопасная очистка фото профиля перед удалением аккаунта
  - Добавлено логирование с ID пользователя для аудита
  - Улучшена обработка ошибок при удалении файлов
  - Улучшена документация с явным указанием на необратимость операции

#### 4. Обновление сериализаторов
- **Файл**: `users/serializers.py` - `UpdateProfileSerializer`
- **Изменения**:
  - Добавлена валидация размера фото (максимум 5MB)
  - Добавлена валидация типов файлов (JPEG, PNG, GIF)
  - Добавлены информативные сообщения об ошибках

#### 5. Обновление модели User
- **Файл**: `users/models.py` - поле `profile_photo`
- **Изменения**:
  - Добавлена справка (help_text) о поддерживаемых форматах и ограничениях

### 🔒 Требования безопасности

1. **Аутентификация**: Требуется JWT токен для всех операций
2. **Верификация**: Удаление аккаунта требует подтверждение пароля
3. **Валидация**: Все фото проходят проверку размера и типа
4. **Очистка**: Старые файлы автоматически удаляются из хранилища
5. **Логирование**: Все операции удаления логируются для аудита

### 🧪 Тестирование

Для тестирования функциональности:

1. **Смена фото**:
```bash
curl -X PUT http://localhost:8000/api/users/update-profile/ \
  -H "Authorization: Bearer TOKEN" \
  -F "profile_photo=@photo.jpg" \
  -F "name=New Name"
```

2. **Удаление фото**:
```bash
curl -X DELETE http://localhost:8000/api/users/update-profile/ \
  -H "Authorization: Bearer TOKEN"
```

3. **Удаление аккаунта**:
```bash
curl -X DELETE http://localhost:8000/api/users/delete-account/ \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"password": "user_password"}'
```

# 🚀 Dream House - AI Ассистент, Скидки и Рекомендации

## 📋 Что было добавлено

### 1. **Запросы на скидки** (Discount Requests)
- Пользователи могут предложить свою цену на карточку
- Автоматический расчет процента скидки
- История запросов с статусами (pending, approved, rejected)
- Админ может одобрить/отклонить с комментарием
- Сохранение original_price для сравнения

**Модель:** `DiscountRequest`
```python
fields:
- card (ForeignKey)
- user (ForeignKey)
- original_price (текущая цена карточки)
- requested_price (желаемая цена)
- discount_percent (автоматически вычисляется)
- status (pending, approved, rejected)
- message (комментарий пользователя)
- admin_comment (ответ админа)
```

### 2. **Алгоритм рекомендаций** (Recommendations)
- Анализирует избранные карточки пользователя
- Находит похожие по городу, типу дома, рейтингу
- Сохраняет рекомендации с оценкой релевантности (0-1)
- Автоматически генерирует при первом запросе
- Исключает уже просмотренные и избранные

**Модель:** `Recommendation`
```python
fields:
- user (ForeignKey)
- card (ForeignKey)
- score (0-1, релевантность)
- reason (текстовое объяснение)
- created_at
```

### 3. **AI Ассистент** (ChatGPT/Claude интеграция)

#### Конфигурация AI
**Модель:** `AIAssistant`
```python
fields:
- name (название ассистента)
- api_provider (openai, anthropic, disabled)
- api_key (сохраняется в БД, но лучше использовать env переменные)
- model_name (gpt-4, claude-3-opus и т.д.)
- system_prompt (инструкция для AI)
- temperature (0-1, творческость ответа)
- max_tokens (максимальная длина ответа)
- is_active (включен/отключен)
```

#### История чатов
**Модель:** `ChatMessage`
```python
fields:
- user (ForeignKey)
- message (вопрос от пользователя)
- response (ответ от AI)
- referenced_cards (ManyToMany связь с упомянутыми карточками)
- tokens_used (для подсчета статистики)
- is_helpful (отзыв пользователя о качестве ответа)
- created_at
```

### 4. **AI Service** (`cards/ai_service.py`)

Основной класс `AIAssistantService` обрабатывает:
- Поиск по предпочтениям пользователя
- Вызов API (OpenAI или Anthropic)
- Сохранение истории чатов
- Привязка рекомендуемых карточек к чату

**Использование:**
```python
from cards.ai_service import AIAssistantService

ai = AIAssistantService()

# Получить ответ от AI
result = ai.chat(
    user_message="Найди мне квартиру из 3 комнат в Махачкале до 3 млн",
    user_preferences={
        'city': 1,  # Махачкала
        'rooms': 3,
        'price_max': 3000000
    },
    user_id=123  # сохранить в историю
)

if result['success']:
    print(result['response'])
    print(f"Использовано токенов: {result['tokens_used']}")
    print(f"Упомянуто карточек: {result['referenced_cards']}")
```

## 📊 Админка

### Управление DiscountRequest
- Список всех запросов на скидки
- Фильтр по статусу и городу
- Автоматический расчет процента скидки
- Админ комментарии при одобрении/отклонении
- Защита от редактирования обработанных запросов

### Управление Recommendation
- Просмотр рекомендаций для каждого пользователя
- Оценка релевантности (score)
- История создания

### Управление AI Ассистентом
- Активировать/деактивировать
- Выбор провайдера (OpenAI/Anthropic)
- Настройка параметров (temperature, max_tokens)
- Редактирование system prompt
- Примечание: API ключ лучше установить через env переменные

### История чатов
- Просмотр всех чатов пользователя
- Упомянутые карточки
- Обратная связь (is_helpful)
- Количество использованных токенов

## 🧠 Как работает алгоритм рекомендаций

1. **Сбор данных:**
   - Получить все избранные карточки пользователя
   - Получить города и типы домов из избранных
   - Исключить уже просмотренные

2. **Фильтрация:**
   - Оставить только карточки из предпочтённых городов
   - Отфильтровать по типу дома
   - Отсортировать по рейтингу и свежести

3. **Оценивание:**
   - Первый результат = 1.0 (идеальный)
   - Второй = 0.95
   - Третий = 0.90 и т.д.

4. **Сохранение:**
   - Сохранить в БД для быстрого доступа
   - Использовать при последующих запросах

---

## 🤖 Как работает AI ассистент

1. **Обработка сообщения:**
   - Получить сообщение от пользователя
   - Спарсить предпочтения

2. **Поиск в БД:**
   - Запросить карточки по предпочтениям
   - Форматировать информацию для контекста

3. **Вызов API:**
   - Отправить промпт с контекстом в OpenAI/Claude
   - Получить ответ

4. **Сохранение:**
   - Сохранить в `ChatMessage`
   - Привязать упомянутые карточки
   - Подсчитать использованные токены

5. **Обратная связь:**
   - Пользователь может оценить ответ (is_helpful)
   - Использовать для улучшения в будущем

## 🐛 Возможные проблемы и решения

### "AI Assistant is not configured"
**Проблема:** Ассистент не активирован в админке
**Решение:** 
1. Идите в `/admin/`
2. Создайте запись AIAssistant с `is_active=True`
3. Выберите провайдера и добавьте API ключ

### "OpenAI API key not found"
**Проблема:** Ключ не установлен
**Решение:**
```bash
export OPENAI_API_KEY="sk-your-key-here"
```

### "ConnectionError" при чате
**Проблема:** Нет интернета или API недоступен
**Решение:** Проверьте интернет и API статус провайдера

## 🔒 Безопасность

1. **API Ключи:**
   - Никогда не коммитьте ключи в гит
   - Используйте переменные окружения
   - Ограничьте права доступа в админке

2. **Чаты:**
   - Пользователь видит только свои чаты
   - Admin видит все истории

3. **Рекомендации:**
   - Персонализированы для каждого пользователя
   - Не содержат приватной информации

## 📈 Масштабирование

Если будет много запросов к AI:

1. **Кеширование:**
   - Кешировать часто задаваемые вопросы
   - Использовать Redis для быстрого доступа

2. **Асинхронные задачи:**
   - Использовать Celery для обработки чатов
   - Не блокировать основной поток

3. **Оптимизация поиска:**
   - Использовать Elasticsearch вместо SQL
   - Добавить полнотекстовый поиск

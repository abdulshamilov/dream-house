🔐 Авторизация

Получение токена

POST /api/users/token/

Авторизация пользователя по номеру телефона или email. Возвращает пару JWT-токенов.

Запрос:

{
  "phone_number": "+79991234567",
  "password": "your_password"
}

Ответ 200:

{
  "access": "eyJ0eXAiOiJKV1QiLCJhbGc...",
  "refresh": "eyJ0eXAiOiJKV1QiLCJhbGc..."
}
💡 Использование: Добавьте заголовок Authorization: Bearer {access_token} ко всем защищённым запросам.

Обновление токена

POST /api/users/token/refresh/

Запрос:

{
  "refresh": "{refresh_token}"
}

Ответ 200:

{
  "access": "new_access_token"
}

🔍 Поиск и фильтрация

Поиск по тексту

GET /api/cards/search/?q=центр

Фильтрация карточек

GET /api/cards/?city=1&price_max=5000000

Доступные фильтры:

Параметр Тип Описание
search string Поиск по названию/адресу
city integer ID города (1, 2, 3, 4)
complex_type string residential, apart
house_type string brick, panel, monolith и т.д.
price_min number Минимальная цена
price_max number Максимальная цена
rooms_min integer Минимум комнат
rooms_max integer Максимум комнат
area_min number Минимальная площадь (м²)
area_max number Максимальная площадь (м²)
developer integer ID застройщика
balcony boolean true/false
loggia boolean true/false

Примеры:

Двухкомнатные квартиры в Махачкале до 5 млн: 
GET /api/cards/?city=1&rooms_min=2&rooms_max=2&price_max=5000000
Монолитные дома с лифтом и балконом: 
GET /api/cards/?house_type=monolith&elevator=cargo_passenger&balcony=true

🤖 AI Ассистент

Чат с AI

POST /api/cards/ai/chat/
Требует авторизации

Запрос:

{
  "message": "Найди мне двухкомнатную квартиру в Махачкале до 5 млн",
  "mode": "search",
  "user_preferences": {
    "city": 1,
    "rooms_min": 2,
    "rooms_max": 2,
    "price_max": 5000000
  }
}

Параметр mode:

  • search — Поиск с результатами из БД
  • free — Свободный чат без поиска

История чата

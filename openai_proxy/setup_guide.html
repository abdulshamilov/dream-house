Подготовка голландского сервера

Подключаемся к серверу по SSH:

ssh root@IP-вашего-голландского-сервера

Устанавливаем необходимые пакеты:

# Обновление системы и установка Python, nginx, certbot
apt update && apt install -y python3 python3-pip python3-venv nginx certbot python3-certbot-nginx
2

Загрузка файлов на сервер

На вашем компьютере (PowerShell) выполните:

# Переходим в папку проекта
cd C:\Users\abdul\Desktop\dream_house

# Копируем папку openai_proxy на сервер
scp -r openai_proxy root@IP-СЕРВЕРА:/opt/
Замените IP-СЕРВЕРА на реальный IP-адрес вашего голландского сервера
3

Настройка прокси

На голландском сервере:

# Переходим в папку
cd /opt/openai_proxy

# Создаём виртуальное окружение Python
python3 -m venv venv
source venv/bin/activate

# Устанавливаем зависимости
pip install -r requirements.txt

# Создаём файл настроек
cp .env.example .env
nano .env

Заполняем файл .env:

# Ваш ключ OpenAI (получить на platform.openai.com)
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxx

# Ключ Anthropic (опционально, console.anthropic.com)
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxx

# Секретный ключ для авторизации (сгенерируйте ниже)
PROXY_SECRET_KEY=ваш-секретный-ключ

# Настройки кеширования
CACHE_ENABLED=true
CACHE_TTL=3600
PORT=8080

Генерируем секретный ключ:

openssl rand -hex 32
Важно! Скопируйте сгенерированный ключ и сохраните — он понадобится для настройки основного сервера.
4

Запуск прокси как системного сервиса

Создаём файл сервиса systemd:

nano /etc/systemd/system/api-proxy.service

Вставляем содержимое:

[Unit]
Description=API Proxy Server
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/openai_proxy
Environment="PATH=/opt/openai_proxy/venv/bin"
EnvironmentFile=/opt/openai_proxy/.env
ExecStart=/opt/openai_proxy/venv/bin/gunicorn --workers 2 --bind 127.0.0.1:8080 app:app
Restart=always

[Install]
WantedBy=multi-user.target

Запускаем сервис:

# Перезагружаем конфиг systemd
systemctl daemon-reload

# Включаем автозапуск
systemctl enable api-proxy

# Запускаем сервис
systemctl start api-proxy

# Проверяем статус
systemctl status api-proxy

# Тестируем
curl http://localhost:8080/health
Должен вернуть: {"status": "ok", "openai_configured": true, ...}

Настройка HTTPS (nginx + Let's Encrypt)

Создаём конфиг nginx:

nano /etc/nginx/sites-available/api-proxy

Вставляем (замените домен на свой):

server {
    listen 80;
    server_name proxy.ваш-домен.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 120s;
        proxy_connect_timeout 120s;
    }
}

Активируем конфиг и получаем SSL сертификат:

# Создаём символическую ссылку
ln -s /etc/nginx/sites-available/api-proxy /etc/nginx/sites-enabled/

# Проверяем конфиг nginx
nginx -t

# Перезагружаем nginx
systemctl reload nginx

# Получаем бесплатный SSL сертификат
certbot --nginx -d proxy.ваш-домен.com

Проверяем HTTPS:

curl https://proxy.ваш-домен.com/health

Настройка основного сервера (Россия)

На российском сервере редактируем .env в папке dream_house:

nano /path/to/dream_house/.env

Добавляем строки:

# URL прокси на голландском сервере
OPENAI_PROXY_URL=https://proxy.ваш-домен.com

# Тот же секретный ключ, что указали на прокси
OPENAI_PROXY_SECRET=ваш-секретный-ключ

Перезапускаем Django:

# Если используете gunicorn через systemd
systemctl restart gunicorn

# Или supervisor
supervisorctl restart dream_house
Готово! Теперь AI чат автоматически работает через голландский прокси.

🔐 Бонус: VPN за 5 минут

На голландском сервере выполните:

cd /opt/openai_proxy
chmod +x setup_wireguard.sh
bash setup_wireguard.sh

Скрипт автоматически:

  • Установит WireGuard
  • Сгенерирует ключи
  • Покажет QR-код для телефона

Приложения WireGuard:

  • Android: Google Play → "WireGuard"
  • iPhone: App Store → "WireGuard"
  • Windows: wireguard.com/install

Бонус: Автоматический бэкап базы данных

На голландском сервере отредактируйте скрипт:

nano /opt/openai_proxy/backup_db.sh

Измените строки:

MAIN_SERVER="root@IP-российского-сервера"
REMOTE_DB_PATH="/path/to/dream_house/db.sqlite3"

Настройте SSH-ключи для подключения без пароля:

# Генерируем ключ
ssh-keygen -t ed25519

# Копируем на основной сервер
ssh-copy-id root@IP-российского-сервера

Добавьте задачу в cron (ежедневно в 3:00):

crontab -e

Добавьте строку:

0 3 * * * /opt/openai_proxy/backup_db.sh >> /var/log/backup.log 2>&1
✓

Проверка что всё работает

На голландском сервере:

# Статус прокси
systemctl status api-proxy

# Логи в реальном времени
journalctl -u api-proxy -f

# Статистика кеша
curl -H "X-Proxy-Auth: ваш-секретный-ключ" https://proxy.ваш-домен.com/stats

На основном сайте:

Просто используйте AI чат как обычно — запросы автоматически пойдут через прокси.

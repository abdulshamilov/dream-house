## 4. API Endpoints (через Postman или curl)

### A. Смена пароля
```
POST /api/users/change-password/
Headers: Authorization: Bearer <access_token>
Body:
{
  "old_password": "current_password",
  "new_password": "new_password",
  "new_password_confirm": "new_password"
}
Ожидается: 200 OK
```

### B. Обновление профиля
```
PUT /api/users/update-profile/
Headers: Authorization: Bearer <access_token>
Body:
{
  "name": "New Name",
  "profile_photo": <file>  // опционально
}
Ожидается: 200 OK с обновленными данными
```

### C. Удаление аккаунта
```
DELETE /api/users/delete-account/
Headers: Authorization: Bearer <access_token>
Body:
{
  "password": "user_password"
}
Ожидается: 204 No Content
```

### D. Список отзывов на карточку
```
GET /api/cards/{card_id}/user-reviews/
Headers: Authorization: Bearer <access_token> (опционально)
Ожидается: 200 OK с массивом отзывов
```

### E. Создать отзыв
```
POST /api/cards/{card_id}/user-reviews/
Headers: Authorization: Bearer <access_token>
Body:
{
  "rating": 5,
  "text": "Отличная квартира!"
}
Ожидается: 201 Created
```

### F. История AI чатов (последние 10)
```
GET /api/cards/ai/history/
Headers: Authorization: Bearer <access_token>
Ожидается: 200 OK с массивом (максимум 10 сообщений)
```

### G. Подборка для меня
```
GET /api/cards/recommendations/
Headers: Authorization: Bearer <access_token>
Ожидается: 200 OK с массивом похожих карточек
```

### H. Кураций карточки
```
GET /api/cards/{card_id}/curations/
Headers: Authorization: Bearer <access_token> (опционально)
Ожидается: 200 OK с JSON:
{
  "card_id": 1,
  "curations": [
    {
      "id": 2,
      "address": "...",
      "price": 1500000,
      "rooms": 2,
      "city": "Махачкала",
      "rating": 4.5,
      "title": "..."
    },
    ...
  ]
}
```

## 7. Проверка парсеров AI
```bash
python manage.py shell

# В shell:
from cards.ai_service import AIAssistantService
ai = AIAssistantService()

# Цена
price_min, price_max = ai._parse_price_from_text("до 2млн")
assert price_max == 2_000_000, f"Ожидается 2000000, получено {price_max}"

# Комнаты
rooms = ai._parse_rooms_from_text("двухкомнатная")
assert rooms == 2, f"Ожидается 2, получено {rooms}"

# Город
city = ai._parse_city_from_text("Махачкала")
assert city == 1, f"Ожидается 1, получено {city}"

# Проверка недвижимости
assert ai._is_realty_related("квартира") == True
assert ai._is_realty_related("погода") == False

print("✓ ВСЕ ПАРСЕРЫ РАБОТАЮТ!")
```

## 8. Проверка истории в AI chat
```bash
# Когда пользователь отправляет запрос к AI:
# 1. AI должен получить последние 10 сообщений из истории
# 2. Добавить их в контекст
# 3. Ответить с учетом контекста

# Проверка:
python manage.py shell

from cards.models import ChatMessage
from django.contrib.auth import get_user_model

User = get_user_model()
user = User.objects.first()

# Вывести последние 10 сообщений
messages = ChatMessage.objects.filter(user=user).order_by('-created_at')[:10]
print(f"Сообщений: {len(messages)}")

for msg in messages:
    print(f"- {msg.message[:50]}...")
```

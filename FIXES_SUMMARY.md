### ✅ 1. Исправление ошибки 500 при загрузке файлов в админке

**Проблема:** При попытке добавления или редактирования карточек с файлами (изображения, видео, документы) админка возвращала ошибку 500.

**Причина:** В файле `cards/signals.py` импортировалась зависимость `channels` без проверки её наличия:
```python
from channels.layers import get_channel_layer
from asgiref.sync import async_to_sync
```
Пакет `channels` не был установлен в окружении, что вызывало `ImportError` при попытке сохранить модель Card.

**Решение:** 
- Добавлена обработка исключений при импорте `channels`
- Пакеты `channels` и `channels-redis` добавлены в `requirements.txt`
- WebSocket-уведомления отправляются только если `channels` установлен

**Файлы изменены:**
- `cards/signals.py` — добавлена защитная обработка импорта
- `requirements.txt` — добавлены `channels==4.1.0` и `channels-redis==4.1.0`

### ✅ 5. Добавление индексов БД для оптимизации (без PostgreSQL)

**Проблема:** На SQLite поиск и фильтрация работают медленнее без индексов, а при масштабировании это станет узким местом.

**Решение:** 
- Добавлены индексы на часто используемые поля:
  - `title` — для поиска
  - `city` — для фильтрации по городам
  - `house_type` — для фильтрации по типу дома
  - `price` — для фильтрации по цене
  - `created_at` — для сортировки
  - `(city, house_type)` — композитный индекс для комбинированной фильтрации
- Добавлена сортировка по умолчанию (`ordering = ['-created_at']`) в Meta класс

**Файлы изменены:**
- `cards/models.py` — добавлены индексы в Meta класс Card
- Создана новая миграция: `0014_alter_card_options_remove_cardquestion_answered_at_and_more.py`

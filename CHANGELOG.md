# 📝 CHANGELOG - Dream House Project

## [FIXED] 11 декабря 2025

### 🔴 КРИТИЧЕСКИЕ ОШИБКИ (исправлены)

#### 1. Ошибка 500 при загрузке файлов в админке
- **Файл:** `cards/signals.py`
- **Проблема:** `ImportError` при импорте `channels` без проверки наличия пакета
- **Решение:** 
  - Обёрнут импорт в try-except блок
  - Добавлена переменная `HAS_CHANNELS` для контроля доступности
  - WebSocket-уведомления отправляются только если channels установлен

#### 2. Дублирующиеся модели
- **Файл:** `cards/models.py`
- **Проблема:** Модель `CardQuestion` определена дважды
- **Решение:** Удалена дублирующаяся версия, оставлена одна

#### 3. Дублирующиеся импорты
- **Файл:** `cards/serializers.py`
- **Проблема:** `CardQuestion` импортирована в двух местах
- **Решение:** Удалена вторая строка импорта

### 🟡 УЛУЧШЕНИЯ И ОПТИМИЗАЦИИ

#### 1. Улучшение поиска
- **Файлы:** `cards/views.py`, `cards/filters.py`
- **Изменения:**
  - Добавлен поиск по `address` (было только title и description)
  - Добавлена проверка на пустой query параметр
  - Реализован методический фильтр `filter_search()` в CardFilter
  - Теперь работает без PostgreSQL, используя SQLite индексы

#### 2. Оптимизация базы данных
- **Файл:** `cards/models.py`
- **Добавлены индексы на поля:**
  - `title` — для поиска по названию
  - `city` — для фильтрации по городу
  - `house_type` — для фильтрации по типу дома
  - `price` — для фильтрации по цене
  - `created_at` — для сортировки
  - Композитный индекс `(city, house_type)` — для комбинированной фильтрации
- **Добавлена сортировка:** `-created_at` (новые в начале)

#### 3. Регистрация сигналов
- **Файл:** `cards/apps.py`
- **Добавлено:** Метод `ready()` для импорта `cards.signals` при инициализации приложения

#### 4. Конфигурация Django
- **Файл:** `config/settings.py`
- **Изменено:** `DEBUG = True` для разработки (było False)
- **Примечание:** В production нужно установить False!

#### 5. Зависимости
- **Файл:** `requirements.txt`
- **Добавлено:**
  - `channels==4.1.0` — WebSocket и асинхронная поддержка
  - `channels-redis==4.1.0` — Redis backend для channels
